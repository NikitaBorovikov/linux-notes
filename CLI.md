## 🔸 Навигация 
 
|  |  |
| --- | --- |
| `/` | Корневой каталог |
| `~` | Домашний каталог (/home/username) |
| `.` | Рабочий каталог (где сейчас находитесь) |
| `..` | Родительский каталог (на один уровень выше рабочего) |
| `pwd` | Вывести название рабочего каталога |
| `ls` | Вывести список содержимого каталога |
| `ls -la` | Получить подробный список содержимого каталога со скрытыми файлами |
| `cd` | Перейти в другой каталог |

- **Абсолютный путь** начинается с корневого каталога и перечисляет все "ветви дерева", отделяющие корень от нужного каталога или файла.
- **Относительный путь** начинается с рабочего каталога.   

## 🔸 Управление файлами и каталогами

| Команда | Описание |
| --- | --- |
| `mkdir` | Создать новый каталог |
| `rm` | Удалить файл или каталог |
| `rm -r` | Рекурсивно удалить каталоги |
| `cp` | Скопировать файл или каталог |
| `cp -r` | Рекурсивное скопировать каталог и его содержимое |
| `cp -u` | Скопировать только те файлы, которых нет в каталоге назначения или более новые |
| `mv` | Переместить/переименовать файл или каталог |

- Флаг `-i`: запрашивает подтверждение пользователя перед исполнением команды.
- Флаг `-v`: выводит информацию о процессе выполнения команды. 

## 🔸 Работа с файлами

| Команда | Описание |
| --- | --- |
| `file` | Просмотреть информацию о файле |
| `less` | Просмотреть содержимое файла |
| `cat` | Объединить файлы (или вывести содержимое небольшого файла) |
| `sort` | Отсортировать строки текста |
| `uniq` | Найти или удалить повторяющиеся строки. |
| `wc` | Посчитать число строк, слов и байтов в файле |
| `grep` | Найти строки, соответствующие шаблону |
| `head -n` | Вывести первые n строк файла |
| `tail -n` | Вывести последние n строк файла |
| `tail -f` | Выводит последние строки файла в реальном времени. |

## 🔸 Групповые символы

### • Основные шаблоны
| Символ | Его смысл |
| --- | --- |
| `*` | Любая последовательность любых символов |
| `?` | Один любой символ |
| `[символы]` | Один символ из указанного множества |
| `[!символы]` | Один символ, не принадлежащий указанному множеству |
| `[[:класс:]]` | Один символ, принадлежащий указанному классу |

### • Классы символов

| Класс | Его смысл |
| --- | --- |
| `[:alnum:]` | Любая буква или цифра |
| `[:alpha:]` | Любая буква |
| `[:digit:]` | Любая цифра |
| `[:lower:]` | Любая буква в нижнем регистре|
| `[:upper:]` | Любая буква в верхнем регистре|

## 🔸 Работа с командами
| Команда | Описание |
| --- | --- |
| `type` | Просмотреть тип переданной команды (исполняемая программа, встроенная команда, функция командной оболочки или псевдоним) |
| `which` | Определить местоположение выполняемого файла (ищет только исполняемые программы) |
| `help` | Получить справку для встроенной команды |
| `--help` | Получить инструкцию по использованию исполняемой команды |
| `man` | Получить справочное руководство по использованию команды |
| `whatis` | Получить очень краткое описание команды из руководства |
| `alias <name>='команда'` | Создать псевдоним для команды |
| `unalias <name>` | Удалить псевдоним для команды |

## 🔸 Перенаправление
Можно перенаправить ввод/вывод команды. Например, сделать так, чтобы результат выполнения какой-либо команды выводился не в консоль, а в созданный нами файл. 
| Символ | Описание |
| --- | --- |
| `>` | Оператор перенаправления (с перезаписью файла) |
| `>>` | Оператор перенаправления (с добавлением в конец файла) |
| `\|` | Оператор конвейера. Отправить вывод одной команды на вход другой |

## 🔸 Подстановки
 `echo` - команда, которая просто выводит на экран свои аргументы.

| Подстановка | Пример | Результат |
| --- | --- | --- |
| Арифметические выражения | `$((3 + 7))` | `10` |
| Фигурные скобки | `echo Число_{1..3}_вывод`  | `Число_1_вывод, Число_2_вывод, Число_3_вывод` |
| Параметры | `echo $USER` | `your_username` |


## 🔸 Экранирование

| Способ | Описание |
| --- | --- |
| `""` | Все спец. символы (кроме `$`, `\`, `` ` ``) потеряют свое спец. значение |
| `''` | Все спец. символы потеряют свое спец. значение |
| `\` | Экранирование только одного конкретного символа |
