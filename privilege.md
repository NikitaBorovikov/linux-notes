## 🔸 Пользователи

Linux поддерживает многопользовательскую работу, то есть компьютером могут пользоваться сразу несколько человек. 
У каждого пользователя свои права на конкретные файлы. Пользователи могут объединяться в группы. 

- Данные о пользователях хранятся в файле `/etc/passwd`.
- Данные о группах хранятся в файле `/etc/group`.
- Пароль пользователя хранится в файле `/etc/shadow`.

| Команда | Описание |
| --- | --- |
| `id` | Выводит информацию о пользователе |
| `chmod` | Изменяет режим доступа к файлу |
| `su` | Запускает командную оболочку от имени другого пользователя (Если пользователь не указан, подразумевается суперпользователь)|
| `sudo` | Выполняет команду от имени другого пользователя |
| `chown` | Изменяет владельца файла |
| `chgrp` | Изменяет группу пользователя |
| `passwd` | Изменяет пароль пользователя |
| `adduser` | Добавляет нового пользователя |
| `whoami` | Выводит имя текущего пользователя |

## 🔸 Атрибуты файла

При выполнении `ls -l` выводятся права доступа (первые 10 символов):
- Первый символ: тип файла (`-` - обычный файл, `d` - каталог, `l` - символическая ссылка).
- 2-4 символы: привилегии для владельца файла.
- 5-7 символы: привилегии для группы.
- 8-10 символы: привилегии для всех остальных. 

| Атрибут | Описание |
| --- | --- |
| `r` | Разрешение на чтение |
| `w ` | Разрешение на запись |
| `x ` | Разрешение на выполнение |

Изменять права доступа к файлу может только владелец файла. 

## 🔸 Суперпользователь
**root** - это суперпользователь в Linux с максимальными правами доступа к системе (UID=0). 
- Полный доступ ко всей файловой системе
- Управление пользователями и группами
- Управление процессами (может завершить любой процесс)
- Установка и удаление программного обеспечения
- Изменение системных настроек
