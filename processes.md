| Команда | Описание |
| --- | --- |
| `ps x` | Выводит список всех процессов текущего пользователя |
| `ps aux` | Выводит список всех процессов всех пользователей |
| `<имя_программы> &` | Запуск программы в фоновом режиме |
| `kill <PID>` | Завершает процесс |
| `killall <имя_программы>` | Завершает все процесс программы |
| `pstree` | Выводит список процессов в виде древовидной структуры, отражающей отношения «родитель—потомок» между процессами |
